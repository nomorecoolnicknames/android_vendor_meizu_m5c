# Meizu M5c (m5c) vendor blobs

Proprietary files for the Meizu M5c (m5c, MT6737M), LineageOS 20.0.

Used by [android_device_meizu_m5c](https://github.com/nomorecoolnicknames/android_device_meizu_m5c) (`lineage-20.0`).

Source: stock Flyme 6.0.2.4G (Android 6.0). Some blobs are patched at build time by the scripts in this directory
(`blob-path-patch.py`, `blob-elf-wire.py` with `treble-elf-wiring.txt`, `blob-parcel-box.py`). `firmware/spm/` is
generated from the GPL kernel source, see its README.

The proprietary files are property of Meizu and MediaTek and keep their original terms.
